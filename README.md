# Dental Guardian
โปรเจกต์นี้เป็นส่วนหนึ่งของรายวิชา Software Design and Development 2 จัดทำขึ้นเพื่อพัฒนาระบบเว็บไซต์สำหรับคลินิกทันตกรรม ช่วยให้ผู้ป่วยเข้าถึงประวัติการรักษาทางทันตกรรม จัดการการนัดหมาย และจองคิวได้สะดวกยิ่งขึ้น

## 📌 ภาพรวมโครงการ
Dental Guardian เป็นโครงการพัฒนาเว็บไซต์ที่มุ่งแก้ไขปัญหาการเข้าถึงข้อมูลการรักษาทางทันตกรรม และช่วยให้การใช้บริการคลินิกสะดวกขึ้น

### ปัญหาที่ต้องการแก้ไข
- ผู้ป่วยอาจจำไม่ได้ว่าเคยรักษาฟันซี่ใดหรือได้รับการรักษาอะไรไปแล้ว
- ผู้ป่วยอาจต้องรอคิวนานเมื่อคลินิกมีผู้ใช้บริการจำนวนมาก
- ผู้ป่วยอาจลืมวันหรือเวลานัดหมาย ทำให้คลินิกต้องติดตามข้อมูลเพิ่มเติม

### แนวทางแก้ไข
- จัดเก็บและแสดงประวัติการรักษาทางทันตกรรม
- แสดงข้อมูลการรักษาผ่านผังฟันที่เข้าใจง่าย
- รองรับการจองคิวและการจัดการนัดหมาย

## 🚀 วิธีติดตั้งและเริ่มใช้งาน

### 1. ดาวน์โหลดโปรเจกต์

```bash
git clone <REPOSITORY_URL>
cd Dental_Guardian
```

### 2. สร้างสภาพแวดล้อม Python

```powershell
py -3.14 -m venv .venv
```

### 3. เปิดใช้งานสภาพแวดล้อม

```powershell
.venv\Scripts\Activate.ps1
```

### 4. ติดตั้งแพ็กเกจ

```bash
python -m pip install -r requirements.txt
```

### 5. ตั้งค่าตัวแปรแวดล้อม

สร้างไฟล์ `.env` ตามตัวแปรที่โครงการต้องใช้ โดยอ้างอิงจาก `.env.example` หากมี

> ห้ามเผยแพร่รหัสผ่าน กุญแจ API หรือข้อมูลลับลง GitHub

### 6. เริ่มเปิดเว็บไซต์

```bash
python -m reflex run
```

เปิด URL ที่แสดงใน Terminal เพื่อเข้าใช้งานเว็บไซต์
